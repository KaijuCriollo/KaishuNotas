# Kaishu Notas

App de pendientes para el celu. Sin login y sin base de datos: todo se guarda en el navegador del teléfono.

## Cómo funciona
- **Arrastrados**: pendientes de días anteriores, con la etiqueta "hace N días".
- **Nuevos / Para hoy**: lo que cargaste hoy.
- **Hechos hoy**: lo que tildaste queda tachado (tocalo de nuevo para desmarcarlo) y se borra solo al día siguiente.
- **Fondo**: botón de imagen arriba a la derecha → elegir una foto del celu y ajustar cuánto se oscurece.

## Publicar en GitHub Pages
1. Crear un repo nuevo (ej. `kaishu-notas`) y subir todos los archivos tal cual, incluida la carpeta `icons/`.
2. En el repo: **Settings → Pages → Build and deployment → Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Esperar uno o dos minutos y abrir `https://<tu-usuario>.github.io/kaishu-notas/`.

## Instalar en el celular
- **Android (Chrome)**: menú ⋮ → *Agregar a la pantalla principal* / *Instalar app*.
- **iPhone (Safari)**: botón Compartir → *Agregar a inicio*.

## Ojo
- Los datos viven en ese navegador de ese teléfono. Si borrás los datos del navegador, se pierden los pendientes.
- En iPhone, abrila siempre desde el ícono instalado: Safari y la app instalada guardan datos por separado.
